Catatan Guru Kejuruan (Instruktur UKK): Aturan Penetapan Alamat Default Gateway

Pada standar Cisco Packet Tracer dan Uji Sertifikasi BNSP TKJ, alamat Usable Host Pertama (192.168.10.1) umumnya dialokasikan sebagai Interface Router (Default Gateway). Alamat Network ID (.0) dan Broadcast (.255) secara mutlak TIDAK BOLEH dipasang pada NIC komputer klien karena dilindungi oleh standar RFC 1122.
